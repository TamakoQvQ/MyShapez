# MyShapez

基于Qt的一个类异形工厂游戏

## 关于游玩

`Myshapez`文件夹内为源码，`release`为打包好的文件夹。若要运行，打开`relese`文件夹并运行其中的`MyShapez.exe`即可。

## 背景

《异形工厂》是一款关于建立工厂，自动创建以及关于形状组合的游戏。玩家在游戏中需要交
付符合要求的越来越复杂形状的开采物，在游戏中不断进步，并解锁升级以加快你的工厂生产速度。游戏很轻松，只需建造工厂，布好设施，无需操作即能自动创造出各种各样的几何图形。此为一个简化版本的类异形工厂游戏。

## 规则简介

- 主游玩界面为一张地图，中心为交付中心，交付中心的数字显示当前持有的金币；地图上存在红色和蓝色两种开采物。其中，蓝色开采物可以被切割机切割，粉色则不可以。
- 游戏目标是利用开采器开采地块来得到相应的产物，并通过在地块上放置传送带等设备将产物运送到交付中心。成功运送开采物到交付中心可以获得金币。
- 游戏有任务设定，界面右下方指示每种开采物的当前已交付数量/需要交付的数量。完成任务后可以对设备进行升级（开采器的速率、传送带的速率、切割机的速率）。

## 如何操作

- 下方菜单栏上的设备依次是：开采器，传送带（直），传送带（弯），切割机，垃圾桶，旋转器。
- 左键点击菜单栏上的相应卡片会改变光标形状，表示接下来即将放置该建筑；右键再次点击该卡片可以旋转。（注意只有在选卡区旋转才有效，光标移到地图上再旋转无效）
- 点击卡片后，在地图上相应地块再次单击左键执行放置。
- 点击传送带（直）卡片后在地图上拖动，可以实现传送带的连续放置。
- 右键单击地图上的建筑可以删除该建筑

## 修改存档 

按下`S`键后会在D盘创建一个`MyGame.txt`文件作为存档。如要测试相应功能，可以修改存档对应行的内容。每一行的数据依次对应如下：
- 是否强化过开采物所在地块的数量，为0表示未强化
- 是否强化过每种开采物成功交付后得到的金币数量，为0表示未强化
- 金币总数
- 交付中心大小，初始为3，强化后为4
- 每次交付开采物得到的金币量，初始为2，强化后为5
- 开采器产生开采物的时间，初始为100，升级后为50
- 切割机切割开采物的时间，初始为200，升级后为100
- 传送带的速度，初始为1，升级后为2
- 获得的蓝色开采物总量，上限为20
- 获得的红色开采物总量，上限为30
- 获得的蓝色切割开采物（左半）总量，上限为50
- 获得的蓝色切割开采物（右半）总量，上限为50

请不要改动此`txt`文件的位置，否则会导致读档失败。
